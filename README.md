# wordDict
a teeny tiny personal vocabulary notebook for language learners like me! 

you see, something i do to learn Russian actively, is i write a daily diary but in russian.. so naturally, i run into words i don't know all the time.

for example, i might write something like:

ya nravitsya cake (notice how cake is english while the rest is russian...)

...and I realise I have no idea how to say cake in Russian :(

so I look it up, learn that it's торт (tort), and add it to my ledger.

the next time I want to write cake, i already know it :D

please export csv every once a while ESPECIALLY before switching browsers or nuking your laptop. or you will be one sorry fucker like me woops. 

if you want to not download csv every few days, just make a free firebase account with the email you will use to log in. its FREE and for a dictionary you won't ever run out.

there is no Google Translate, no AI, and no automatic dictionary, no API bs.

you look up the translation yourself.

it sounds slower, but actually it's better— you read the word twice, pay attention to it, and remember it far more often.
